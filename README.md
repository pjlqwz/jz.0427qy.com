# jz.0427qy.com · 千羽网络锦州城市站

服务锦州及辽西地区的千羽网络城市站。栏目与功能对齐主站 www.0427qy.com，内容按锦州语境重写或导入改造。

## 与主站的三条边界（改内容前必读）

1. **不虚构本地存在。** 千羽的注册主体、办公地、团队都在盘锦，锦州没有办公室或分公司。
   页面上只写「服务锦州」，不写「锦州分公司」「锦州本地团队」。地址与 JSON-LD 里
   `address` 一律写盘锦（真实），只有 `areaServed` 写锦州。
2. **不复制主站正文。** 主站的 60 个成品站模板页、1466 篇资讯文章不整站照搬——
   复制只会造出重复页面，搜索引擎按 doorway/镜像站处理，还会拖累主站权重。
   成品站超市与小程序展厅用「框架形式」落地：功能一个不少，但本站只生成 1 个 URL。
3. **不编造案例与数据。** 凡数字必有公开来源（锦州市统计局公报 / 市工信局 / 市发改委）。
   资讯文章的虚构案例与虚构人物已在导入时删句处理，见「文章导入」一节。

## 成品站超市的框架形式（沿用营口站做法）

功能与主站等价，但**本站只生成 `/template/` 一个 URL**，避免 60 个与主站重复的详情页：

- 列表页：60 张卡片按行业分组，顶部「锦州常见」快捷筛选（锦州主导产业 → 模板分类映射）
- 点卡片 → 全屏框架层：左侧先给本地高清截图（秒开），右侧自带栏目 / 什么情况下选它 /
  千羽建议 / 不适合的情况 + 「就按这个改，报价给我」；「加载真实演示站」按钮**按需**挂
  iframe 到 demo 站，「看完整方案」链主站详情页
- **真站绝不能开场就挂**：实测 demo 站同一编号两次请求 6 秒 / 40 秒超时都有。
  默认给图、真站按需点；18 秒还没打开就撤掉 iframe 退回截图，按钮变「真站没打开，再试一次」

## 发布链路（固定五步）

```bash
cd web && node node_modules/astro/astro.js build   # 产物到 web/dist
python tools/gen_sitemap.py                        # 新增页面必跑
python tools/deploy.py                             # dry-run 看清单
python tools/deploy.py --apply                     # dist → 仓库根
git add -A && git commit && git push origin main   # push 即发布
```

- 改完源码必须重新 build 再 deploy，否则发的是上一版产物。
- 改 `web/public/` 下的资源也必须 build（只 deploy 不会搬新文件 → 线上 404）。
- `web/dist` 是 gitignore 的，仓库根才是产物区。
- 非产物目录要登记到 `tools/deploy-keep.txt`，否则 deploy 会按「产物里没有」删掉。
- Astro 的构建残留（`chunks/`、`pages/`、根层 `*.mjs`）会漏到仓库根，已在 `.gitignore` 挡下。
